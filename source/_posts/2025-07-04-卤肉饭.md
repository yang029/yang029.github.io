好久不做卤肉饭！之前都是linden做的，今天我来偷师下看怎么样

1. 原材料

- 五花肉：我在大华买的非常漂亮的五花肉，肥瘦相间
- 香菇，木耳：提前泡发，切成丁。
{% asset_img 1.jpg "image" %}
- 洋葱切小块
{% asset_img 4.jpg "image" %}
- 生姜切片
- 料汁：五勺生抽，两勺蚝油，一勺老抽，一块冰糖，料酒，

2. 锅里放水，五花肉放在蒸笼上，水开后蒸20分钟。据说这样做比焯水更好去腥味。蒸到筷子能戳透就可以了。

{% asset_img 2.jpg "image" %}

3. 五花肉放进冰箱冷藏一会，等肉硬后方便切丁。

{% asset_img 3.jpg "image" %}

4. 锅中倒一点点油，把五花肉丁放进去煸炒出油后出锅。
{% asset_img 5.jpg "image" %}

> * 煸到表面金黄就可以出锅了。我会把煎出来的油倒掉大部分

{% asset_img 6.jpg "image" %}

5. 用锅里剩下的油炒香洋葱和生姜片，随后加入五花肉丁、香菇丁和木耳丁炒香。

{% asset_img 7.jpg "image" %}

6. 随后加入料汁炒出酱油香气，加水没过食材，加八角，桂皮，香叶，干辣椒，大火烧开后转小火20分钟

{% asset_img 8.jpg "image" %}

然后便可以出锅啦，我是水煮了一些青菜，放在米饭上，然后把卤肉汁浇在上面。就是标题的效果，整体味道非常不错。

## 可能的改进

和外面的卤肉饭差别最大的一点就是---没有卤蛋。理论上讲是把鸡蛋提前煮好，然后在卤肉汁里泡上一晚上。可惜卤肉饭太香了我们直接两顿吃完了没有留到第二天🤦‍。下次可以多做一点试试。
