今天算是做了一顿大餐，连带准备和做饭把一上午一中午都搭了进去。不过出品确实相当满意。

## 蒸鲈鱼

### 原材料:

big mouth sea bass(大口鲈鱼)：这次的鲈鱼是在中国超市99ranch买的，新鲜现杀，从在水里游泳到上桌加起来不过两个小时。买的时候员工会帮忙处理鱼鳞和内脏，拿回家差不多是这个样子

{% asset_img 1.jpg "image" %}

### 做法:

1. 鱼处理好后用清水冲洗干净，再用刀在鱼身上刮一刮看有没有鱼鳞残留。一般背部可能会有一些，处理掉可以吃的时候口感更好。

2. 鱼身上平着划几刀

{% asset_img 2.jpg "image" %}

3. 在鱼身上抹盐，大概全身有一层就可以了。我为了去腥还抹了一层料酒。同时生姜切小片，葱切成葱丝，方便塞进鱼身上和肚子里。

{% asset_img 3.jpg "image" %}

4. 随后把生姜和葱丝塞进鱼肚子里面和身上划出的刀口里面。腌制二十分钟左右

{% asset_img 4.jpg "image" %}

5. 腌制好后把鱼放在盘子里。

> * 注意要尽量把鱼立起来放。之前其实应该在盘子上面交叉放两根筷子，这样更好立起来。我这里忘放了，也为后面埋了伏笔。

{% asset_img 5.jpg "image" %}

6. 蒸锅里面放水，水开后把鱼放进去。

{% asset_img 6.jpg "image" %}

> 这个蒸锅是我在网上找了好久才买到的，能放下鱼盘的大锅，对比下正常的锅就能看出来了。🤦‍

{% asset_img 19.jpg "image" %}

7. 放进鱼后盖盖子转中小火，只需要**7分钟**就可以了。到点了可以打开用筷子戳一戳鱼身，可以戳进去就说明蒸好了。

{% asset_img 7.jpg "image" %}

> 这里会发现我的鱼不知道什么时候偷偷倒了🤦‍。不过不影响整体口感。

8. 出锅后把鱼身上的葱姜片和鱼肚子里的葱姜片都拿掉，锅底的水也要倒干净，这些都会比较腥。然后上面摆上葱花和蒜片。

{% asset_img 8.jpg "image" %}

9. 接着起锅烧油，油冒烟后泼在鱼身上，激发出葱蒜的香味。同时倒上蒸鱼豉油。

{% asset_img 9.jpg "image" %}

这样鱼就可以上桌啦。虽然整体流程比较繁琐，但是真的是一等一的鲜。鱼肉筷子夹就能掉下来，口感非常嫩滑。鲈鱼的刺也很少，吃起来非常方便。

{% asset_img 10.jpg "image" %}

## 清炒squash

### 原材料:

squash(西葫芦)：squash是在costco买的。本来只想买zucchini，但结果它捆绑销售，就决定尝尝这个了

### 做法:

1. squash切片

{% asset_img 11.jpg "image" %}

2. 半个洋葱切成大块

{% asset_img 12.jpg "image" %}

3. 蒜切片

{% asset_img 13.jpg "image" %}

4. 锅中放油，油热后放入洋葱炒香， 然后放入蒜片

{% asset_img 14.jpg "image" %}

> 后放蒜片是因为洋葱炒的比较久，蒜片后放就不会炒糊了

5. 随后放入squash翻炒，加入糖，生抽，蚝油和少许盐调味

6. 等到squash变软出水后就可以出锅了

（我忘记拍炒好的图了🤦‍ 具体就看封面吧）

这道菜整体非常清爽，虽然国内从来没见过黄色的西葫芦但是口感可以说是一模一样。

## 皮蛋拌豆腐

### 原材料:

- 皮蛋两只
- 嫩豆腐一块 在wholefoods买的叫silken tofu
- 小米辣四个 （非常辣，一点点就够了）

### 做法:

1. 葱切成葱花，蒜切成蒜末，小米辣切成小段备用

{% asset_img 15.jpg "image" %}

2. 调料汁，我是三勺生抽，两勺醋，一勺蚝油，再加上少许糖和香油

3. 皮蛋剥壳切成1/4 大小，豆腐撕开封口倒扣在盘子上，然后用刀划成小块

{% asset_img 16.jpg "image" %}

> * 皮蛋非常难切，切的时候要用比较短的刀慢慢划开。如果刀背上沾了水或者前一只皮蛋的蛋黄会导致皮蛋黏在刀上，所以每切一刀都要用纸巾擦一下。

4. 随后把料汁浇在皮蛋和豆腐上面，最后撒上葱花，蒜末和小米辣。我刚好要烧油于是顺便泼了一下，正常流程是不用的

{% asset_img 17.jpg "image" %}

总结下来就还是好吃的，但是嫩豆腐会一直出水，下次要注意把水倒干净再浇汁。
