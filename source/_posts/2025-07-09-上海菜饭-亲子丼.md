## 上海菜饭

### 原材料

- 大米：2杯
- 腊肠：3根
- 上海青：10个
- 火腿：少许（理论上讲应该用腊肉，但确实买不到，用伊比利亚火腿代替了）

### 做法

1. 腊肠火腿切片，和米饭一起放进锅里，加入平常煮饭2/3的水量，正常煮熟
   {% asset_img 1.jpg "image" %}

> * 少加水是希望有一些锅巴，后面拌入青菜的时候青菜也会出水

2. 上海青洗净切小段。注意叶子要切大一点，因为会缩水。
    {% asset_img 2.jpg "image" %}

3. 上海青放进锅里爆炒一下。同时加少许盐和糖调味

    {% asset_img 3.jpg "image" %}

4. 炒到出水就可以出锅了，然后把上海青倒入整好的米饭里面拌匀。
    {% asset_img 4.jpg "image" %}

5. 最后保温模式再焖上20分钟就可以吃了

    {% asset_img 5.jpg "image" %}

## 亲子丼（oyakodon）

这其实是有点地狱的名字，把鸡和儿子炖在一起了🤦‍

### 原材料

- 鸡腿肉
- 洋葱（optional）
- 鸡蛋

### 做法

1. 鸡腿肉提前加入少许生抽腌入底味，鸡蛋打散
    {% asset_img 6.jpg "image" %}

> * 注意鸡蛋只需要稍微打散就可以

2. 鸡腿肉放入锅中小火两面煎至微微金黄
    {% asset_img 7.jpg "image" %}
    {% asset_img 8.jpg "image" %}

3. 然后加入酱汁煮十分钟
    - 酱汁：两勺酱油，一勺味淋，一勺料酒，一勺寿司醋，少许糖，少许水
    {% asset_img 9.jpg "image" %}

4. 待只剩下底上一层汤汁的时候，加入打散的鸡蛋，不用搅动，等到鸡蛋半熟就可以出锅了
    {% asset_img 10.jpg "image" %}
