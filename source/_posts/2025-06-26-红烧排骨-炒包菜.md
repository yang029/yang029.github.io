今天中午做了红烧排骨和炒包菜，都是比较常规的熟手菜

## 红烧排骨

1. 提前两个小时把排骨拿出来泡水，目的是去血水
2. 接一锅清水，倒入少许料酒，冷水放入排骨焯水。水开后两三分钟捞出排骨

{% asset_img 1.jpg "image" %}

3. 在焯水的同时准备调料，酱汁我放了一勺老抽，两勺耗油，三勺生抽，出来味道还可以。香料的话就是常规的姜片，八角，桂皮，香叶，干辣椒。（没有放花椒因为不想吃到花椒xs）

{% asset_img 2.jpg "image" %}

4. 锅中放油，油热后放入排骨煎至两面微黄，随后加入调料炒香

{% asset_img 3.jpg "image" %}

</br>

{% asset_img 4.jpg "image" %}

5. 最后加入酱汁，待炒出香味后加入热水，稍微没过排骨即可。大火烧开后转小火盖盖20分钟。

> * 加入酱汁前火要调小，不然酱汁容易糊有苦味
> * 加入热水是为了防止排骨表面温度骤降导致肉质变硬
> * 水不用加太多，不然收汁时间会变长，肉质也会老。

{% asset_img 5.jpg "image" %}

6. 20分钟后打开盖子，收汁到只有锅底一层液体即可。不要收的太干，剩下的都是油烧不干的

{% asset_img 6.jpg "image" %}

> * 这次感觉排骨质量不佳，大小不一导致有的有点柴，下次要选大小均匀有点肥肉的排骨

## 干锅包菜

1. 首先包菜切丝，切一些蒜片备用

> * 其实理想情况应该是手撕成小块，然后把硬的菜梗手动挑出来，这样口感和出来的品相都会更好。但我手撕了试了下，两三分钟才处理了一两片，时间有点紧就放弃了🤦‍。这里手动@上次来家里做客撕了20分钟包菜的hym，确实很花时间，辛苦了哈哈哈哈。

{% asset_img 7.jpg "image" %}

2. 锅中放油，先倒入少许花椒，待花椒微微变黑捞出

> * 注意要用高烟点的油，不然就会有很多烟然后烟雾报警器开始响
> * 我这一次采用直接用把锅直接倒在滤网上面下面用碗接着油，这样就不用用筷子/勺子一点点挑花椒了

{% asset_img 8.jpg "image" %}

3. 随后锅中放入蒜片和干辣椒炒香

> * 干辣椒我会体现用手撕开把里面的籽到掉，这样炒出来不会影响口感
> * 这次放了三个干辣椒炒出来巨辣，下次感觉放一个就可以了

{% asset_img 9.jpg "image" %}

4. 随后放入包菜丝翻炒，中途放入少许糖，生抽，和盐调味

> * 生抽可以溜着锅边放，利用高温蒸发出香气

{% asset_img 10.jpg "image" %}

5. 具体火候可以自己把握，我是不断的去尝，可以选择生一点脆一点和软一点好咀嚼的口感

> * 一定要全程保持大火，出锅的时候锅底是干的最好。
