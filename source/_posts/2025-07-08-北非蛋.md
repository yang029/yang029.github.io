北非蛋（Shakshuka）！啊已经是做了好几次的菜了，基本上做法都大同小异。

## 原材料

- 鸡蛋：2 * {吃饭的人数}
- 番茄：1/3 个番茄罐头 * {吃饭的人数}
- 洋葱：半个 
- 青椒：半个 （optional）
- 大蒜：2 瓣
- 香肠：四根 （optional）
- 辅料：盐，胡椒粉，孜然粉，橄榄油

{% asset_img 1.jpg "image" %}

## 做法

1. （有香肠的话）先把香肠切片，放入锅中煎出油

{% asset_img 2.jpg "image" %}

2. 锅中再加入橄榄油，放入洋葱炒香，随后加入大蒜和青椒炒香

{% asset_img 3.jpg "image" %}

3. 加入番茄炒出汁，随后加入盐，胡椒粉，孜然粉调味

{% asset_img 4.jpg "image" %}

4. 把锅中的食材推到一边，留出空位，打入鸡蛋。鸡蛋上也可以撒上盐和胡椒粉调味

{% asset_img 5.jpg "image" %}

5. 盖上锅盖，焖煮3-5分钟，直到蛋白凝固，蛋黄还保持流动状态

{% asset_img 6.jpg "image" %}

6. 出锅前可以撒上西芹碎和芝士（optional）

7. 搭配面包或者 pita 一起吃

## 小结

北非蛋是一道非常自由的早餐，主味就是洋葱和番茄，其余的配料都可以根据家里的库存和个人喜好来调整。做法也非常的简单，可以多做！
