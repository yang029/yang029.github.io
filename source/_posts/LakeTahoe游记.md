## 乘兴而至

在周四的时候我的一个关系挺好的同事H突然找我，问我有没有兴趣周末去Lake Tahoe(太昊湖) 玩一圈，周五去周日回。 我也是当下就答应了啊，感觉与其一个人在家里自闭不如出去走走。后来和他的聊天也是证明了此行非虚。

这次总共的行程也就我和他加上他的同学W。 在周四的时候我们开了一个小会，大概定了行程和酒店(我也是第一次出发前一天才定酒店xs)。没想到居然找到了两晚上只要600刀的airbnb，总体来说还是非常不错的。

## 意外总是不期而至

W是在harvard读PHD然后暑假在santa barbara的GOOGLE实习，所以计划是他周五下班后坐飞机到SFO大概八点，然后我和H七点多出发去SFO接他，之后一路向东北。大概晚上十二点能到。虽然可能累了点但也还算是可以接受。结果万万没想到W的飞机超级延误了，我们等到了十一点多才接到了他，然后便是迎着浓浓夜色向tahoe奔去。

## 路上谈心

因为在机场等了一下午，上车后不久就在后座沉沉睡着。而我怕司机犯困，一路上也是不停的找话题去聊。没想到一聊天才知道我这同事居然已经准备跳槽了，他从三个月前就开始准备面试，一路面了google， amazon和microsoft等等公司，目前google已经面过了一轮bq 两轮coding，还有一轮team match面好像，现在基本上就是在等offer了。

我细细问了他原因，感觉主要有如下几点:

1。 在arista工作的经验和技巧很难去transfer到别的公司。
   a. 因为首先我们公司的系统架构非常的特殊，我们为了reliability设计的数据库只支持single writer和multiple writer。 导致我们在设计的时候不用去处理concurrency 的问题。但这个可能反而是system design中的核心问题。所以我们会缺乏这方面的能力
   b. 再者network这个领域本身就相对比较狭窄，主要做network的公司就没有几家，再者我们个体也只是做network方向的一小部分领域导致我们在工作中积累的network方向的专业知识很难去apply到别的工作岗位中去
   c. 我们公司的语言也比较特殊，全世界可能也只有一家公司使用，

   因为以上的这些因素，导致一个人在arista干的越久，职级越高，越难以去跳到别的公司薪水更高的岗位。因为他并不能具备别的公司higher level所拥有的能力。也正因为如此，他觉得每天花在工作上面的时间是低效的，是不能给他带来更多未来竞争力的提升的。

   这里我感觉就跟我的mindset出现了很多差距，因为我的思路是上班是赚钱，就会expect自己是在那时间和精力赚钱。会有点强迫自己喜欢上做的事。仔细思考这其实跟我一路学习的经历也有原因。我感觉一直做的都不是特别喜欢的事情，上各种辅导班，竞赛之类的。都是家长觉得我需要去上，我才去上的，然后就是慢慢的逼着自己喜欢上这些事情。但老实说感觉他这种思考方式还是更积极向上一些。

2. 他的rsu一直没有refresh导致tc比我大改低了20k一年
3. 他觉得这些事情只有年轻的时候可以做，并且他觉得AI会是未来的趋势，所以他想去尝试一下AI相关的工作。

### Kayak

{% asset_img 7.jpg "image" %}

Kayak 其实就是一种小型的独木舟，人坐在里面用浆划船。我们报名了一个日落的Kayak tour，本来一直很担心天气不好看不到，没想到到了傍晚天气突然慢慢转晴了，也算是意外之喜。

在tour开始前我们每个人都被分到了一支巨大无比的桨，大概比我还高上不少。同时向导也对我们进行了简单的教学，其实主要就是要两只手平行的握住桨，中间距离大概是肩宽，然后用腰部核心的力量去划桨，而不是手臂的力量。胳膊尽量伸直，要保证两只胳膊，桨叶和身体中间的四边形是正方形。

划起来后我还有一些感觉就是要感受桨叶在慢慢排开水的感觉，如果能感觉到自己在发力排水，船就会划的更快。

在Kayak入水的一瞬间，我其实有点慌张，毕竟很少双脚真正的离开大地，总是担心船会翻。但在Kayak在水上慢慢平静后，慢慢的开始摇桨，我也是逐渐发现这项运动并没有那么难，心情也是逐渐放松下来。

一路上跟着向导，不知不觉岸就在身后远去，我也划得越来越如臂使指，望着远处连绵的群山，感受着小船在波光粼粼的湖面上随着波浪轻轻摇摆，我感觉自己仿佛一片飘在水上的落叶，完全融入了这片湖水之中。

{% asset_img 8.jpg "image" %}

> 舟行碧波上，人在画中游。

不知不觉也是到了傍晚，天空先是变为蓝宝石一般的青色，然后被夕阳染成梦幻的淡粉色，真的让人流连忘返。

{% asset_img 9.jpg "image" %}

小注意事项
Kayak划船一定会把裤子和屁股弄湿，因为水会在换桨的时候顺着流到腿上，所以建议穿速干裤或者泳裤。

### Bar

在Kayak tour结束后，H和W觉得需要有意思一点的夜生活，于是搜了下附近的酒吧。我们就开过去点了两杯酒。说实话我是第一次在美国去酒吧，但莫名的非常喜欢这种氛围，昏暗的灯光，嘈杂的音乐，五光十色的霓虹灯，嘈杂的人声中，我坐在吧台的角落，默默的啜饮手中的酒。莫名有种闹市中的孤独的感觉。我点了一杯martini，一杯Moscow mule，调酒师做的非常快，也是让我大开眼界。但是martini有点水水的，我感觉不是很dry，不是很喜欢

## Day 2

### Emerald Bay

第二天大家起来就已经不早了，大家早饭都没吃，就向着south Tahoe出发了。本来准备去Emerald Bay的，但没想到停车场都是爆满根本没有地方停车，我们也只能路边停下来大概看了看，也只能说爆满不是没有道理的，湾中的湖面仿佛一块天然的蓝宝石水滴吊坠，深邃而美丽

{% asset_img 11.jpg "image" %}

### Himmel Haus

一家**超级无敌好吃**的德国餐厅。整体设施都非常复古，实木的桌子和椅子，墙上甚至还贴着柏林墙倒塌的报纸哈哈。

主要点了这几道

1. Wurst (香肠)
2. Sauerbraten (慢炖牛肩肉)
3. Spätzle (德国面疙瘩)
4. Schweinebraten (烧猪肘子)

{% asset_img 12.jpg "image" %}

香肠总共上了四种，Bratwurst(猪肉香肠)， BockWurst (牛肉香肠) 以及两种野味香肠，分别是鹿肉和鸭肉。香肠是煎香后上桌的，底下铺着酸菜，甜菜和土豆泥。我个人更喜欢前两种香肠，感觉肉质更加香一些。野味香肠中放入了很多香料导致盖住了原本的味道。

{% asset_img 13.jpg "image" %}

慢炖牛肩肉可以说是全场MVP了，牛肉非常的软烂，入口即化。上面还铺着一层酸菜，底下是土豆泥。酸菜的酸味完美中和了牛肉的油腻，让人一口一口根本停不下来

Spatzle味道也不错，感觉跟碱水结形状很像，但是是热的，口感也更加松软。搭配一同上来的红葱头和蘑菇酱，味道非常的棒。

猪肘子是我期待了超级久的一道菜，味道也还是不错的，感觉就是小了一点，整体还是相当入味的。

### Sacramento

这座加州的首府一直以来存在感都很低，但当我真正stop by的时候，感觉还是相当的peaceful的，我们停在了它的tower bridge旁边，然后在桥上走了一圈。这座桥是经典的升降桥，整个桥身可以升起让船只通过。整个桥通体被漆成金色，在阳光的照射下闪闪发光。桥边上有非常不错的自行车道和步道，河中则是飘着各式的游艇，充满了浓浓的生活气息。

{% asset_img 14.jpg "image" %}

看到桥旁边的介绍，它其实是在大萧条时期建成的，突然就和我常玩的钢铁雄心IV连接起来了，莫名感受到了穿越历史的感觉以及美国曾经的辉煌。

沿着tower bridge看向远处，就可以看到加州州议会大厦，和白宫非常的相似。

{% asset_img 15.jpg "image" %}

### 最后一顿晚餐

最后在回家的路上，W谈到他当时在berkley读书的时候有家非常喜欢的中国餐厅，叫“hong kong east ocean restaurant”，于是我们就决定去那里吃一顿。我们到的时候已经九点了，刚好赶上他们的last call吃上了饭。饭店是经典的广式茶餐厅，我们奢侈了一把点了避风塘炒龙虾，确实好吃。还有一些早茶什么的，都相当正宗。

{% asset_img 21.jpg "image" %}

这家饭店本身的地理位置也非常有意思，是在一个深入海中的半岛上，有非常不错的海景。吃完饭在海边散步，远处还能隐隐看见sf的天际线。

{% asset_img 16.jpg "image" %}

转头一看，金黄晚霞里有飞鸟掠过，可真是

> 落霞与孤鹜齐飞，秋水共长天一色
