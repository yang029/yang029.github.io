家旁边的肉店最近整了新活，开始卖30天的熟成牛排，价格只贵了一点点。所以最近常常买来吃。今天吃的这一块是 1-inch cut 的 ribeye。一块大概30刀。配上简单的香菇炒上海青，两个人吃得很饱。

{% asset_img 5.jpg "image" %}

## 做法

1. 新鲜的牛排买回家双面抹上盐和香料，静置30分钟左右。不用放进冰箱

2. 平底铁锅大火烧热，喷上一点油，油稍微冒烟后放入牛排。我是每面煎了两分钟

> * 油需要用高烟点的油，我这里用的牛油果油
> * 熟成牛排因为比普通牛排水分更少，所以煎的时候时间要适当缩短
> * 不用一直保持大火，看到锅里稍微冒烟就可以把火调小一点了。（烟雾报警器预警）
> * 牛排可以先煎一煎油脂丰富的部位，可以多出一点油也不会很腻

{% asset_img 1.jpg "image" %}

3. 两面煎完后转小火，放入一大块黄油，待其融化后用勺子舀起黄油浇在牛排上，重复五分钟左右。

> * 正常流程还要放入大蒜和迷迭香一起煎，但我前面腌制的料已经混合了各种香料，所以就skip了

{% asset_img 2.jpg "image" %}

4. 牛排内部温度到60度左右出锅，放进盘子里面回温五分钟。

{% asset_img 3.jpg "image" %}

5. 沿着纹路斜切就可以开吃啦，这里看熟度大概是medium ~ medium well，大概就是六七分熟。所以出国回温的时候内部大概又上升了五度左右

{% asset_img 4.jpg "image" %}

## 总结

熟成牛排真的真的非常好吃！！！相比普通牛排，熟成牛排的肉质更细腻，瘦肉一点都不会柴，而且油脂的香味非常浓郁，不会感到非常油腻。从图片也可以看出来基本上没有渗出血水。价格比起在外面吃其实也还是很划算的。下次会尝试控制熟度更加生一些。这次的吃到最后感觉都有点全熟的感觉了。但是一点都不柴！！！怎么吃都好吃
